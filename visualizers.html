Interactive Visualizers

Gradient descent, k-means, the metrics calculator and an entropy explorer.

Four live demonstrations. Each one runs the real algorithm in the browser — nothing is a screenshot — and logs what is happening underneath so you can read the reasoning as the picture changes.

Gradient descent

Press Run and watch the line swing toward the least-squares fit. Change the learning rate: at 0.01 it converges smoothly, at 0.12 it overshoots and the cost climbs. The optimum for this data is \(\theta_0 = 0.8667\), \(\theta_1 = 1.0000\).

Gradient descent on a line fit

k-means

Each press of One iteration performs an assignment step and then an update step — exactly the loop from chapter 11. Watch the SSE fall and the centroids drift. Switch to k = 3 and see it split a natural group in half, which is what happens when you choose the wrong k.

k-means stepper

Metrics calculator

Change the four cells of the confusion matrix and watch all four metrics move together. Try the imbalanced case — set TP = 5, FN = 45, FP = 2, TN = 948 — and note that accuracy stays above 0.95 while recall collapses to 0.1.

Classification metrics

Entropy

Set the class counts and read the impurity. A pure node gives 0; a 50/50 split gives 1 bit, which is the maximum for two classes. This is the quantity the root of every decision tree is trying to reduce.

Entropy explorer

Dependencies

The visualizers are plain JavaScript with no library and run offline once cached. The only external dependencies on the site are Google Fonts (typography), MathJax (equations) and Prism (syntax highlighting). All three degrade gracefully: text falls back to system fonts, equations remain readable, and code appears unstyled but correct.
