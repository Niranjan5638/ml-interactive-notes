The confusion matrix

For binary classification there are four possible outcomes, and every metric is built from them.

Predicted positivePredicted negative
Actual positiveTrue positive (TP)False negative (FN) — a miss
Actual negativeFalse positive (FP) — a false alarmTrue negative (TN)

The four metrics

\[ \text{Accuracy} = \frac{TP+TN}{TP+TN+FP+FN} \qquad \text{Precision} = \frac{TP}{TP+FP} \] \[ \text{Recall} = \frac{TP}{TP+FN} \qquad F_1 = \frac{2 \cdot P \cdot R}{P + R} \]

Precision answers: of everything I flagged, how much was right? Recall answers: of everything that was actually positive, how much did I catch? They trade against each other, and which one matters is a domain decision.

Note F1 is always between precision and recall, and equals both when they are equal. It is the harmonic mean, not the arithmetic mean, so a model that is excellent on one and terrible on the other scores poorly overall.

Why accuracy alone is not enough

The imbalanced-data trap

A fraud dataset has 1 % fraud. A model that predicts "not fraud" always scores 99 % accuracy and catches nothing. Its precision is undefined (no positive predictions), its recall is 0, and it is worthless.

This is why medical and fraud problems report recall and precision rather than accuracy. If an exam asks why accuracy is unsuitable, the answer is that it treats both error types as equally costly, which is almost never true.

SituationFavourReason
Cancer screeningRecallMissing a case is far worse than a false alarm that leads to a retest
Spam filterPrecisionDeleting a real email is worse than letting spam through
Balanced classes, both errors equalAccuracy or F1No asymmetry to exploit

A model has precision 0.95 and recall 0.30. What is it doing?
High precision with low recall means the model is conservative: when it does predict positive it is almost always right, but it only predicts positive for a third of the true positives. To raise recall it must accept more false positives, which lowers precision — that is the trade.

The widest street

Many lines can separate two classes. SVM picks the one with the largest margin — the greatest distance to the nearest point of either class. The intuition is that a boundary with room to spare on both sides is more robust to new data than one squeezing past a training point.

Definitions

Hyperplane — the decision boundary, \(\theta^\top x + \theta_0 = 0\).
Margin — the distance from the hyperplane to the nearest training point.
Support vectors — those nearest points. They alone determine the boundary; every other point could be deleted without changing it.

The equation of a hyperplane

Given a normal vector \(\theta = (a,b)\) and a point \(P_0 = (x_0, y_0)\) on the plane:

\[ a(x - x_0) + b(y - y_0) = 0 \quad\Longrightarrow\quad ax + by + c = 0 \]
Worked example — the plane from a point and a normal

Normal \(\theta = (1,2)\), passing through \(P_0 = (2,1)\).

\(1(x-2) + 2(y-1) = 0 \Rightarrow x + 2y - 4 = 0\).

Check: substituting (2,1) gives \(2 + 2 - 4 = 0\). ✓

Distance from the origin: \(|{-4}|/\sqrt{1^2+2^2} = 4/\sqrt5 = 1.789\).

Maximising the margin

Scale the parameters so that the support vectors satisfy \(\theta^\top x + \theta_0 = \pm 1\). The distance between the two margin planes is then

\[ \text{margin} = \frac{2}{\|\theta\|} \]

Maximising \(\frac{2}{\|\theta\|}\) is the same as minimising \(\|\theta\|\), which is the same as minimising \(\frac{1}{2}\|\theta\|^2\) — the form used because it differentiates cleanly.

The hard-margin objective

\[ \min_{\theta,\theta_0} \frac{1}{2}\|\theta\|^2 \quad\text{subject to}\quad y_i(\theta^\top x_i + \theta_0) \ge 1 \ \ \forall i \]

The constraints say every point is on the correct side and outside the margin. This assumes the data is linearly separable and has no outliers — two assumptions that fail on real data, which motivates the soft margin.

The dual formulation

Introducing a Lagrange multiplier \(\alpha_i \ge 0\) per constraint turns the problem into its dual, which depends only on dot products between points:

\[ \max_\alpha \sum_i \alpha_i - \frac{1}{2}\sum_i\sum_j \alpha_i\alpha_j y_i y_j (x_i^\top x_j) \quad\text{subject to}\quad \alpha_i \ge 0,\ \sum_i \alpha_i y_i = 0 \]

and the solution is recovered as

\[ \theta = \sum_i \alpha_i y_i x_i \]

Two facts follow. First, most \(\alpha_i\) come out exactly zero, and only the support vectors have non-zero \(\alpha\) — which is why the boundary depends on so few points. Second, because only the dot product \(x_i^\top x_j\) appears, you can replace it with a kernel function and never compute the higher-dimensional coordinates at all.

The soft margin

Allow some points to violate the margin, paying a penalty \(\xi_i\) for each:

\[ \min \frac{1}{2}\|\theta\|^2 + C\sum_i \xi_i \quad\text{subject to}\quad y_i(\theta^\top x_i + \theta_0) \ge 1 - \xi_i,\ \ \xi_i \ge 0 \]

The hyperparameter \(C\) sets the trade: large \(C\) punishes violations heavily and gives a narrow margin (risk of overfitting); small \(C\) tolerates violations and gives a wide margin (risk of underfitting).

The kernel trick

If the classes are not linearly separable, map the data into a higher-dimensional space where they are. The kernel trick makes this free: you specify \(K(x_i, x_j) = \phi(x_i)^\top\phi(x_j)\) and the algorithm only ever needs that inner product.

Kernel\(K(x, z)\)Use
Linear\(x^\top z\)Already separable; often best for text
Polynomial\((x^\top z + c)^d\)Curved boundaries of degree \(d\)
RBF (Gaussian)\(\exp(-\gamma\|x-z\|^2)\)Default choice; very flexible
Worked example — why a mapping helps

In one dimension, points at \(x = -1\) (class A) and \(x = +1\) (class B) with a point at \(x = 0\) of class B cannot be separated by a threshold. Map to \(\phi(x) = (x, x^2)\): the points become \((-1,1)\), \((1,1)\), \((0,0)\), and now a line separates \((0,0)\) from the other two. The problem was not linearly separable in 1-D and is in 2-D.

The kernel trick computes \(\phi(x)^\top\phi(z)\) as \((x z + 1)^2\) without ever forming the 2-D vectors.

What is a support vector?
The boundary depends only on the points at the margin — in the dual formulation, only these have non-zero α. Deleting any other training point leaves the hyperplane unchanged, which is what makes SVM relatively robust and memory-efficient at prediction time.
