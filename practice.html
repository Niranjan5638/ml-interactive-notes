Module 1 — Foundations

recall Classify each task as regression, classification or clustering: (a) predicting tomorrow's temperature, (b) grouping news articles by topic, (c) deciding whether a transaction is fraudulent, (d) estimating a house's price.

(a) Regression — the output is a continuous number.
(b) Clustering — unsupervised, no labels, groups emerge from the data.
(c) Classification — the output is a discrete label, and the labels exist in training data.
(d) Regression.

The test is always the same two questions: are there labels, and is the label continuous or categorical?

Module 2 — Regression

applied For the data (1,2), (2,4), (3,6), compute the least-squares line and R².

The points lie exactly on \(y = 2x\), so the fit is \(\theta_1 = 2\), \(\theta_0 = 0\).

Check: \(SS_{res} = 0\), so \(R^2 = 1 - 0/SS_{tot} = 1\).

\(SS_{tot} = (2-4)^2 + (4-4)^2 + (6-4)^2 = 4 + 0 + 4 = 8\), confirming the model explains all of it.

A perfect fit is a warning sign in practice — real data has noise, and \(R^2 = 1\) usually means a feature leaked the target.

exam-hard A model has training MSE 0.02 and test MSE 0.85. Diagnose it and give three remedies.

Overfitting. The gap between training and test error is large — the model has learned the training noise rather than the signal. Its variance is high.

Remedies: (1) more training data, which dilutes the noise; (2) a simpler model — fewer features, lower polynomial degree, shallower tree; (3) regularisation, adding an L1 or L2 penalty to shrink the coefficients. All three reduce variance at the cost of a little bias.

Module 3 — Classification

applied A naive Bayes model has P(Yes) = 0.6, P(No) = 0.4. For a query, the likelihood products are 0.0021 (Yes) and 0.0093 (No). Predict the class and give the normalised probability.

Scores: Yes \(= 0.6 \times 0.0021 = 0.00126\); No \(= 0.4 \times 0.0093 = 0.00372\).

No is larger, so predict No.

Normalised: \(P(\text{No}) = 0.00372/(0.00126 + 0.00372) = 0.747\), \(P(\text{Yes}) = 0.253\).

Note the prior favoured Yes, but the likelihood was strong enough to override it — that is Bayes' theorem doing its job.

applied A dataset has 8 positives and 4 negatives. Compute the entropy and the information gain of a split into two branches with (6 positive, 1 negative) and (2 positive, 3 negative).

Parent: \(H = -\frac{8}{12}\log_2\frac{8}{12} - \frac{4}{12}\log_2\frac{4}{12} = 0.9183\)

Branch 1 (7 rows): \(H = -\frac{6}{7}\log_2\frac{6}{7} - \frac{1}{7}\log_2\frac{1}{7} = 0.5917\)

Branch 2 (5 rows): \(H = -\frac{2}{5}\log_2\frac{2}{5} - \frac{3}{5}\log_2\frac{3}{5} = 0.9710\)

Weighted: \(\frac{7}{12}(0.5917) + \frac{5}{12}(0.9710) = 0.3452 + 0.4046 = 0.7498\)

IG \(= 0.9183 - 0.7498 = 0.1685\)

exam-hard Why can a decision tree achieve zero training error yet perform badly on test data, and what stops it?

An unconstrained tree keeps splitting until every leaf is pure. If it can always find a split that separates one more row, it will eventually isolate every training point in its own leaf — memorising the data, including its noise. Training error goes to zero and generalisation collapses.

Pruning stops it: pre-pruning limits depth or requires a minimum number of samples per leaf, and refuses splits whose gain is negligible; post-pruning grows the full tree then removes branches that do not improve validation accuracy.

exam-hard In an SVM, explain the effect of making C very large, then very small.

Large C — violations of the margin are penalised heavily, so the optimiser accepts almost none. The margin becomes narrow and hugs the data, fitting outliers. Low bias, high variance: overfitting.

Small C — violations are cheap, so the model tolerates points inside the margin to keep the street wide. High bias, low variance: underfitting.

C is therefore the regularisation dial for an SVM, playing the role that λ plays in Ridge and Lasso.

Module 4 — Clustering

applied Run one full k-means iteration on points 1, 2, 6, 7 with k = 2 and initial centroids 1 and 2. Give the new centroids and the SSE.

Assignment: 1 → c₁ (0 vs 1); 2 → c₂ (1 vs 0); 6 → c₂ (5 vs 4); 7 → c₂ (6 vs 5).

Clusters: {1} and {2, 6, 7}.

Update: \(c_1 = 1\); \(c_2 = (2+6+7)/3 = 5\).

SSE \(= 0 + (2-5)^2 + (6-5)^2 + (7-5)^2 = 0 + 9 + 1 + 4 = 14\).

The initialisation was poor — both centroids landed in the same natural group — which is exactly why k-means++ and multiple restarts exist.

applied With eps = 2 and MinPts = 3, classify the points 0, 1, 2, 3, 10 on a line as core, border or noise.

Neighbourhoods within eps = 2 (including the point itself):

  • 0: {0, 1, 2} → 3 → core
  • 1: {0, 1, 2, 3} → 4 → core
  • 2: {0, 1, 2, 3} → 4 → core
  • 3: {1, 2, 3} → 3 → core
  • 10: {10} → 1 → noise

All four of 0–3 are core, so they form one cluster; 10 is noise. Note that a border point appears only when a point has too few neighbours of its own but sits inside a core point's neighbourhood — that did not happen here.

exam-hard Explain precisely why DBSCAN fails on a dataset with two clusters of very different density, and how OPTICS avoids it.

DBSCAN has one global ε. If ε is set to suit the dense cluster, the sparse cluster's points have fewer than MinPts neighbours within ε and are labelled noise. If ε is set to suit the sparse cluster, the dense clusters merge into one, because points between them are within ε of both.

OPTICS does not decide. It computes, for every point, a core distance and then orders the points by reachability distance — the maximum of the predecessor's core distance and the pair distance. Because reachability is floored by the core distance, dense regions produce low values and sparse regions produce high ones, regardless of the absolute distances. The output is a reachability plot whose valleys are clusters at every density simultaneously; you choose the cut afterwards, or use the steepness method to find valleys of any depth automatically.

exam-hard Agglomerative clustering with single linkage and with complete linkage give different dendrograms on the same data. Explain why, and name the failure mode of each.

Single linkage measures cluster distance as the minimum over cross pairs, so a cluster can absorb a new point that is close to just one member. Complete linkage uses the maximum, requiring the new point to be reasonably close to every member.

Single linkage failure — chaining: a chain of intermediate points links two genuinely separate clusters into one, because each consecutive pair is close even though the ends are far apart.

Complete linkage failure — splitting: a single outlier forces a large maximum distance, so compact groups are kept apart longer than they should be, and elongated clusters are broken up.
