Chapter 05

Logistic Regression

Turning a linear model into a classifier with the sigmoid and log-loss.

Textbook-supplied

Your class notes name logistic regression twice but never work it out. This chapter is built from Alpaydin chapter 10 and Géron chapter 4.

Why linear regression cannot be reused

Suppose you want to predict whether a tumour is malignant (1) or benign (0). Fitting a line gives predictions like 0.3 or 1.4 — numbers that are not probabilities and can fall outside \([0,1]\) entirely. Worse, the fit is dominated by points far from the boundary, which is the opposite of what a classifier needs.

What we want is a model whose output is always a valid probability, and whose decision is made by thresholding that probability.

The sigmoid

\[ \sigma(z) = \frac{1}{1 + e^{-z}}, \qquad h_\theta(x) = \sigma(\theta_0 + \theta_1 x) \]

The sigmoid squashes any real number into \((0,1)\): \(z = 0\) gives 0.5, large positive \(z\) approaches 1, large negative approaches 0. So the linear part decides which side and how confidently, and the sigmoid converts that into a probability.

Odds and log-odds

The model is linear in the log-odds, not in the probability:

\[ \log\frac{p}{1-p} = \theta_0 + \theta_1 x \]

This is worth understanding rather than memorising. A coefficient \(\theta_1 = 0.7\) means that a one-unit increase in \(x\) multiplies the odds by \(e^{0.7} \approx 2.01\) — it doubles them. That is a statement you can put in a report; "the probability increases by 0.7" would be meaningless since probabilities are capped at 1.

The decision boundary

Predict 1 when \(h_\theta(x) \ge 0.5\), which happens exactly when \(\theta_0 + \theta_1 x \ge 0\). So the boundary is where the linear part is zero — a point in one dimension, a line in two, a hyperplane beyond.

Worked example — a prediction by hand

Model: \(h(x) = \sigma(-4 + 2x)\). Classify \(x = 3\).

\(z = -4 + 2(3) = 2\). \(h = \sigma(2) = \frac{1}{1+e^{-2}} = \frac{1}{1+0.1353} = 0.8808\).

Since 0.8808 ≥ 0.5, predict class 1, with 88 % confidence.

The boundary is at \(-4 + 2x = 0\), so \(x = 2\): below 2 predict 0, above 2 predict 1.

The cost function, and why not squared error

Using squared error with a sigmoid gives a non-convex cost — it has multiple local minima, and gradient descent can settle in the wrong one. The standard choice is log-loss (binary cross-entropy):

\[ J(\theta) = -\frac{1}{n}\sum_{i=1}^{n}\Bigl[y_i\log h_\theta(x_i) + (1-y_i)\log\bigl(1-h_\theta(x_i)\bigr)\Bigr] \]

Read it as a switch. When \(y = 1\) the second term vanishes and the cost is \(-\log h\) — which is 0 if the prediction was 1 and grows without bound as the prediction approaches 0. When \(y = 0\) the first term vanishes and the cost is \(-\log(1-h)\), symmetric. Confidently wrong predictions are punished enormously; that is what makes it convex with the sigmoid.

Worked example — the cost of one prediction

With \(x = 3\), \(y = 1\), and \(h = 0.8808\):

\(J = -\log(0.8808) = 0.1269\).

Had the model been confidently wrong — \(h = 0.05\) with \(y = 1\) — the cost would be \(-\log(0.05) = 2.996\), roughly 24 times larger. That steep penalty is what drives the parameters away from confident errors.

The gradient

Remarkably, the update rule has exactly the same shape as linear regression:

\[ \theta_j := \theta_j - \alpha \sum_{i=1}^{n}\bigl(h_\theta(x_i) - y_i\bigr)x_{ij} \]

The derivation differs completely, but the result is the residual times the feature. This is not a coincidence — it follows from using the canonical link function for the Bernoulli distribution.

More than two classes

Replace the sigmoid with the softmax, which turns a vector of scores into a probability distribution over \(k\) classes:

\[ \text{softmax}(z)_i = \frac{e^{z_i}}{\sum_{j} e^{z_j}} \]

Binary logistic regression is the special case \(k = 2\). The loss becomes categorical cross-entropy.

Check your understanding

In \(h(x) = \sigma(-4 + 2x)\), what does the coefficient 2 mean?
Logistic regression is linear in the log-odds, so a unit increase in x adds 2 to the log-odds, which multiplies the odds by e² ≈ 7.39. Option 3 is true but is a fact about the intercept and slope together, not about the coefficient on its own.
