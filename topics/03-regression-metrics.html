Chapter 03

Regression Metrics

MSE, MAE, RMSE and R-squared: what each one rewards and punishes.

Why one number is not enough

A regression model makes a real number for every input, so it is almost never exactly right. The metrics below all summarise the residuals — but they summarise different things, and choosing the wrong one lets a bad model look good.

Mean squared error

\[ \text{MSE} = \frac{1}{n}\sum_{i=1}^{n}(y_i - \hat{y}_i)^2 \]

Same quantity as the cost function in chapter 2. Its units are the square of the target's units, so an MSE of 9 on prices in rupees means rupees-squared — not directly interpretable. Its virtue is that it penalises large errors heavily.

Mean absolute error

\[ \text{MAE} = \frac{1}{n}\sum_{i=1}^{n}|y_i - \hat{y}_i| \]

Same units as the target, so directly interpretable: "on average we are off by ₹4,200". It weights every error in proportion to its size, which makes it robust to outliers — one wildly wrong prediction moves MAE by its own size, not its square.

Root mean squared error

\[ \text{RMSE} = \sqrt{\text{MSE}} \]

This exists purely to undo the squaring. It has the same units as the target, like MAE, but still penalises large errors quadratically. The practical rule: RMSE ≥ MAE always, and the size of the gap tells you how concentrated the errors are. If RMSE and MAE are close, errors are uniform; if RMSE is much larger, a few large errors dominate.

Coefficient of determination

\[ R^2 = 1 - \frac{SS_{res}}{SS_{tot}}, \qquad SS_{res} = \sum (y_i - \hat{y}_i)^2, \qquad SS_{tot} = \sum (y_i - \bar{y})^2 \]

\(SS_{tot}\) is the error of the dumbest possible model — always predicting the mean. \(SS_{res}\) is your model's error. So \(R^2\) answers: how much of the variance did I explain, compared to just guessing the average?

  • \(R^2 = 1\) — perfect prediction.
  • \(R^2 = 0\) — no better than predicting the mean.
  • \(R^2 < 0\) — worse than predicting the mean. This is possible on test data and is always a red flag.
Worked example — all four on one dataset

Data: \((1,2), (2,3), (3,5)\). Fitted model: \(\hat{y} = 0.333 + 1.5x\).

Exam trap

\(R^2\) can be negative. Students often assume it is bounded in \([0,1]\), but that is only true if the model is fitted on the same data it is evaluated on. On a held-out test set, a model worse than the mean gives \(R^2 < 0\). If a question asks for the possible range, the answer is \((-\infty, 1]\).

Check your understanding

A model has RMSE = 4.1 and MAE = 1.9. What does the gap tell you?
RMSE squares before averaging, so it is dragged up disproportionately by large residuals, while MAE is not. A gap this wide means the error distribution has a heavy tail: a handful of badly wrong predictions among many good ones. MAE reports the typical error, RMSE reports the worst of it.
